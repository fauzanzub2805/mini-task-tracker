# mini-task-tracker

Frontend: **React + Tailwind CSS + Vite**. Backend: **Laravel + PostgreSQL**.
Halaman login tersedia di `/login`; autentikasi memakai sesi cookie Laravel dan CSRF.
Blade hanya berfungsi sebagai HTML host untuk React, bukan UI halaman.

Panduan menjalankan di localhost, struktur komponen, dan hasil pengujian:
[Frontend login React](docs/progress/frontend-login.md).

Menyusun media untuk proses program magang dengan fungsi menyimpan, mengolah, mengatur, dan mengumpulkan tugas magang kepada mentor/pihak perusahaan, terimakasih 🙏.
